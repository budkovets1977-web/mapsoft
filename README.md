# MAPSOFT / MapWebServer MinskLine

Эталонный проект доработанного **MapWebServer 6.00.60** для БУЗ «Минская линия».

## Состав

- `MapWebServer-6.00.60-MinskLine-r8/` — чистый пакет обновления с вендорской структурой и всеми актуальными исправлениями;
- `docs/` — описания и протоколы выполненных работ;
- `tools/` — вспомогательные проверки пакетов;
- `.opencode/skills/` — перенесённые проектные skills.

Вендорские исходные пакеты (`6.00.60`, `10.01.26 Full`) и архивы (`_archive`) хранятся локально и не публикуются в Git.

## Быстрый старт

1. Сделать резервную копию текущего MapWebServer.
2. Использовать каталог эталонного пакета как обновление поверх соответствующей вендорской версии 6.00.60.
3. Прочитать `MapWebServer-6.00.60-MinskLine-r8/README-MinskLine-r8.md`.
4. Автоматизацию сертификатов устанавливать отдельно на каждой рабочей станции по инструкциям в `automation/`.
5. После установки сверить SHA-256 и проверить работу ЦИСЗ и интерфейса.

Правила дальнейших доработок — в `AGENTS.md`.
