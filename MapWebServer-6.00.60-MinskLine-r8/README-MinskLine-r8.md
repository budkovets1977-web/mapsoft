# MapWebServer 6.00.60 MinskLine r8

Дата сборки: 19.11.2026.

Чистый эталонный пакет на основе вендорского `F:\MAPSOFT\6.00.60` с актуальными доработками рабочего сервера. Основные каталоги и BAT-файлы повторяют структуру вендорского пакета: `bin`, `help`, `reports`, `src`.

Дополнительно включён каталог `automation/` для рабочих станций.

## Что включено

- исправления FHIR и потоковой отправки ЦИСЗ;
- проверка ожидающей регистрации Patient и корректная обработка retryable `-7301`;
- модуль «Отправить в ЦИСЗ за день»;
- исправления очистки зависших сеансов;
- актуальные стили и поведение трёх тем АРМ: `maptheme-ru`, `maptouch-ru`, `comfort-ru`;
- цветные кнопки панели врача, поле врача 450 px и сплит-кнопка печати 112 px;
- автоматический выбор сертификата и автоподтверждение «ОК».

Подробное описание последних изменений: `../docs/ПОСЛЕДНИЕ-ДОРАБОТКИ-20261119.md`.

## Установка обновления

1. Остановить MapWebServer по штатной инструкции.
2. Сделать полную резервную копию текущего каталога MapWebServer.
3. Скопировать файлы пакета поверх вендорской установки **той же версии 6.00.60**, сохраняя структуру каталогов.
4. Не переносить эталон поверх другой версии без отдельного сравнения.
5. Запустить сервер и проверить вход, амбулаторные карты, отчёты и тестовую отправку ЦИСЗ.
6. Сверить контрольные суммы с манифестом пакета.

> Пункт меню «Отправить в ЦИСЗ за день» хранится в БД (`SysMenu`). На новом сервере его необходимо добавить SQL из сохранённого серверного пакета в `_archive/deploy/01-SERVER...`; перед выполнением SQL обязательно сделать резервную копию БД и проверить значения для конкретной инсталляции.

## Автоматизация сертификатов

На каждой рабочей станции отдельно:

1. Открыть `automation/cisz-cert-autoselect/README.md` и установить автовыбор сертификата.
2. Открыть `automation/cert-ok-watcher/README.md` и установить watcher кнопки «ОК».
3. Запускать установщики от пользователя, который работает с МИС и ЭЦП.
4. Проверить первую реальную отправку; первое подтверждение watcher выполняется вручную, последующие — автоматически.

Пароли и ключи в пакет не включаются.
