Главное окно

Главная форма программы появляется после перехода по URL, введенному в адресную строку браузера, сразу после введения логина и пароля зарегистрированного пользователя. Интерфейс главного окна по умолчанию состоит из следующих основных областей.

1 — хедер (шапка) программы. Содержит следующие элементы: 1.1 — название текущей организации; 1.2 — логин пользователя, авторизованного в системе; 1.3 — профиль пользователя; 1.4 — вход в раздел помощи; 1.5 — выход из программы на страницу авторизации.

2 — область меню (второго уровня). Содержит следующие элементы: 2.1 — кнопка сворачивания/разворачивания меню; 2.2 — название текущей задачи; 2.3 — кнопка для доступа в главное меню программы (доступно также при клике на область с названием задачи); 2.4 — подпункты (подзадачи) текущей задачи, при клике открывается соответствующая форма в рабочей области; 2.5 — группы подпунктов текущей задачи, при клике разворачиваются до дочерних элементов верхнего уровня.

3 — рабочая область. Здесь отображается форма любой подзадачи, выбранной из меню второго уровня.

4 — панель задач (область вкладок). Здесь отображаются названия всех открытых форм в виде вкладок.
