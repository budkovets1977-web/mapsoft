Картотека пациентов. Поиск

В поле поиска вводится с клавиатуры текстовая строка, которая служит условием для отбора записей в картотеке. В зависимости от цели поиска (ФИО, адрес, номер а/к, перс.номер, № индивид.карты) правила ввода и применение условия в программе отличается. Цель поиска устанавливается вручную, либо автоматически. Поиск применяется после подтверждения ввода клавишей <Enter>, либо кнопкой .

Регистр букв (заглавные, строчные) при поиске не учитывается, можно всё вводить в одном регистре.

При вводе выражения для поиска можно использовать «символы маски». Символ «_» указывает на любой знак. Символ «%» - на любую, в т.ч. пустую последовательность знаков. Таким образом, можно формировать условия поиска по неполным данным: «П_шкин» позволит найти значения «Пушкин», «Пашкин», «Пешкин» и т.п., «%огов» - «Огов», «Рогов», «Пирогов» и т.п.

☝При поиске по адресу номер дома, корпуса, квартиры – всегда ищется «по точному совпадению», без учета состояния переключателя. Если всё же нужно задать неточное условие на номер – можно воспользоваться символами маски.

•Поиск (универсальный поиск). Если включен «универсальный» поиск, цель определяется автоматически следующим образом:

➢Если введена последовательность цифр, не содержащая букв, пробелов и т.п. – выполняется поиск по номеру амбулаторной карты и по действующему номеру индивидуальной карточки пациента.

➢Если введено одно или несколько (через пробел) слов, и последовательность не содержит цифр, а также точек – выполняется поиск по ФИО.

➢Если есть и буквы, и цифры, либо точки – выполняется поиск по адресу.

☝Для универсального поиска поиск по персональному номеру не используется.

•ФИО (поиск по ФИО). Ищет "по первым". Можно вводить одно, два или три слова – они трактуются как фамилия, имя и отчество соответственно. Разделитель между ними – пробел. Если нужно, например, пропустить фамилию и задать только имя и отчество – нужно поставить пробел в начале. Аналогично, чтобы задать фамилию и отчество – нужно разделить их двумя пробелами. На практике удобнее всего для поиска по ФИО вводить несколько первых букв фамилии, далее инициалы: «вас а б» - Васильев Александр Борисович (а также Василевский Андрей Брониславович и т.п.). Такой способ наиболее простой и дает наиболее точные результаты. Если набрать больше букв (более точное условие) – пациент может быть не найден, если в его ФИО есть опечатка. Если набрать менее точное условие (например, только фамилия или её часть) – будет найдено слишком большое число пациентов. В сомнительных случаях рекомендуется использовать символы маски, например, заменять символом «_» гласные буквы фамилии, которые могут писаться не так, как воспринимаются на слух («Касач»/«Косач» - лучше искать «к_сач»).

•№ А/К (поиск по номеру амбулаторной карты), ПИН (поиск по персональному идентификационному номеру), НИКМО (поиск по номеру индивидуальной карты медицинского обслуживания). Ищут "по вхождению". Никаких особенностей не имеет. Поиск ищет записи, которые содержат введённое поисковое выражение.

•Адрес (поиск по адресу). Ищет "по первым". Можно ввести наименование населенного пункта, тип населенного пункта, наименование улицы, тип улицы, номер дома, корпус и квартиру, например: «г.минск пр.пушкина 25/1 8». Ни один из элементов не является обязательным, в большинстве случаев выражение может быть проще, например: «пуш 25 8». В целом условие поиска по адресу задаётся просто, естественным образом, и не требует специальной подготовки. Но если в определенных ситуациях возникают сложности, можно ознакомиться с нижеследующими правилами.

➢Вначале идет наименование населенного пункта, затем наименование улицы, затем номер дома (может быть с корпусом), затем номер квартиры. Элементы разделяются пробелом. Любые элементы могут отсутствовать, но порядок их следования всегда такой.

➢Корпус задаётся вместе с номером дома через «/» или через «\». В то же время, если номер дома имеет вид «25/18» (угловой дом), поиск будет выполнен успешно, т.к. введенное после «/» будет проверяться как в корпусе, так и непосредственно в номере дома.

➢Квартира задаётся после номера дома через пробел. Задать квартиру без номера дома – невозможно.

➢Перед наименованием населенного пункта можно указать его тип («г.», «п.», «д.» и т.п.). Также перед улицей может быть указан её тип («ул.», «пер.» и т.п.). Тип обязательно должен завершаться точкой – только за счет этого он и определяется как тип. Даже в случаях, когда точка практического смысла не имеет (проезд - «пр-д»), её нужно ставить. Поиск типа н/п или улицы выполняется в соответствующих справочниках, поэтому нужно использовать такое же сокращение, как в справочнике. Например, если в справочнике «бульвар» сокращён как «б-р», нельзя использовать сокращение «бул.», можно «б-р.» или просто «б.». Пробел после точки не обязателен (не обязательно отделять наименование от типа пробелом).

➢Если наименование состоит из нескольких слов, либо начинается с цифры, либо содержит точку в названии, его нужно вводить в кавычках: «п."б.берест" первом 10 12» – пгт Б.Берестовица, ул.Первомайская д.10 кв.12; «"17" 15» – ул. 17 сентября, дом 15.

➢Если указано два наименования – считается, что это населенный пункт и улица (в таком порядке). Если указано только одно наименование – то априори считается, что это улица. Если нужно указать наименование населенного пункта и дом, т.к. наименования улицы в адресе нет (часто встречается в сельской местности) – можно указать перед названием соответствующий тип. Если тип соответствует населенному пункту – при поиске будет считаться, что задан населенный пункт. Например, адрес «деревня Рожковичи, дом 15»: может быть не найдено «рожк 15» (т.к. возможно, есть улица «Рожковая», но на ней нет дома 15), но при поиске по выражению «д.рожк 15» - пациент будет успешно найден. Если заданное наименование не соответствует ни одному наименованию улицы, а соответствует наименованию н/п, поиск успешно пройдет и без указания типа (выполняется предварительная проверка на наличие такой улицы в справочнике), но надежнее в таких случаях указывать тип населенного пункта.

•Поиск+ ("умный" поиск по всем целям). Ищет по всем целям одновременно (ФИО, № А/К, Адрес - "по вхождению"; ПИН, НИКМО - по точному совпадению). Описанные выше правила составления поискового выражения справедливы и для этого типа поиска. Но существуют некоторые особенности в поиске для следующих целей.

➢ФИО. Дополнительные пробелы в поисковом выражении, которыми можно заменить Фамилию/Имя/Отчество не учитываются: будет учтён лишь пробел, разделяющий слова.

➢Адрес. Поиск по данной цели не учитывает угловые дома. Если известно, что в адресе есть угловой дом, то лучше использовать универсальный поиск либо поиск по адресу.

➢№ А/К. Поисковое выражение может содержать любое количество цифр. Результат поиска будет содержать записи со входимостью этого поискового выражения в номер амбулаторной карты. Данный поиск работает совместно с поиском по номеру телефона: если ПВ не меньше 5-ти цифр, то к результатам поиска по номеру амбулаторной карты будут добавлены результаты поиска по номеру телефона.

➢НИКМО. Поисковое выражение должно содержать 16 цифр номера карточки. Только в этом случае будет выполнен поиск по номерам карт медицинского обслуживания и выдачей результата поиска.

➢Поиск по номеру телефона. Для успешного результата поиска поисковое выражение должно содержать не менее 5-ти цифр и желательно без префиксов кодов. Поиск ищет по точному совпадению "с конца" по всем типам номеров телефонов (мобильный, домашний, "без типа"). Например, при поиске по выражению 72580, поиск найдёт пациентов, у которых в номерах телефонов с конца есть данное поисковое выражение: (801775) 7-25-80, (+375017) 317-25-80. Данный поиск работает совместно с поиском по номеру амбулаторной карты: если введенное поисковое выражение содержится в номерах амбулаторных карт, то наряду с результатами поиска по номеру телефона будут представлены и они.
