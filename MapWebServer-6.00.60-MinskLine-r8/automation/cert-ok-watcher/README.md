# CertOkWatcher — авто-подтверждение выбора сертификата ЭЦП (ЦИСЗ)

## Что делает
При пакетной отправке в ЦИСЗ диалог «Безопасность Windows / Выбор сертификата»
(процесс NTClientSoftware, класс окна `Credential Dialog Xaml Host`) больше не
требует нажимать «ОК» на каждой записи:

- первое окно подтверждается вручную;
- все последующие окна закрываются автоматически (кнопка «ОК» через UI Automation);
- если 3 минуты окон нет — снова ждёт ручного подтверждения.

Ввод пароля не затрагивается (NTClientTool.exe и saved.txt со своими паролями
на каждом компьютере остаются как были).

## Состав
- `CertOkWatcher.ps1` — watcher (PowerShell, Win32 + UIAutomation).
- `Install.cmd` — установка.

## Установка на новом компьютере
1. Скопировать папку на компьютер.
2. Убедиться, что установлена и работает связка NTClientSoftware + NTClientTool
   (папка `c:\MAP\Avest\`, автозагрузка NTClientTool).
3. Запустить `Install.cmd` **от того пользователя, который работает с МИС/ЭЦП**
   (двойной клик, права администратора не нужны).
   Install.cmd:
   - копирует `CertOkWatcher.ps1` в `c:\MAP\Avest\`;
   - добавляет автозагрузку в HKCU Run (`CertOkWatcher`);
   - добавляет `skip_cert_window:true` в `%APPDATA%\Avest\saved.txt`
     (встроенная опция NTClientTool; если файла нет — шаг пропускается);
   - сразу запускает watcher.
4. Проверить, что появился процесс powershell (скрытый) и файл
   `c:\MAP\Avest\CertOkWatcher.log` с записью `Watcher started.`

## Проверка
Во время реальной пакетной отправки: первое окно «ОК» вручную, остальные —
сами. В логе появляются строки `Auto-clicked OK.` Если окно не ловится —
смотреть лог и `window-monitor2`-подход (класс/заголовок окна могут отличаться
в другой версии Avest).
