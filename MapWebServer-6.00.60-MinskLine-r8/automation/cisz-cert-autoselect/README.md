# SetCiszCert — автоматический выбор сертификата ЭЦП для отправки в ЦИСЗ

## Суть решения

При отправке пакетов в ЦИСЗ подпись идёт через локальный агент **NT Client Software**
(`C:\NTClientSoftware\NTClientSoftware.exe`, порт 8084). Агент показывает окно выбора
сертификата каждый раз, потому что в `NTClientSoftware.ini` секция `[sigma]` содержит
пустой `cert=`.

Установлено экспериментально (на рабочей машине):

- Если в `[sigma]` записать `cert=<понятное имя сертификата>` (friendly name,
  то, что задаётся в certmgr.msc, напр. «Саттарова Д.Р.») — агент **автоматически
  выбирает этот сертификат**, и окно выбора сертификата **не появляется**.
- Остаётся только окно «Безопасность Windows» (ввод пароля ключа) — его уже
  обрабатывает утилита NTClientTool (пароли в `%APPDATA%\Avest\saved.txt`).
- Значение `cert=` должно быть в кодировке **Windows-1251**.
- Строку `lib=../lib/libnki3.0.so` в `[sigma]` удалять/терять нельзя.

## Файлы

| Файл             | Назначение                                                        |
|------------------|-------------------------------------------------------------------|
| `SetCiszCert.ps1`| Основной хелпер. Читает friendly name активного сертификата (с приватным ключом) и пишет его в `cert=` секции `[sigma]`. Сохраняет `lib=`. |
| `autostart.reg`  | Добавляет хелпер в автозагрузку текущего пользователя.            |
| `install.bat`    | Копирует скрипт в `C:\MAP\Avest\` и применяет `autostart.reg`.    |

## Установка на клиентскую машину

Запустить `install.bat` (от текущего пользователя). Он:

1. Копирует `SetCiszCert.ps1` в `C:\MAP\Avest\`.
2. Применяет `autostart.reg` — добавляет в автозагрузку запись
   `powershell ... -File C:\MAP\Avest\SetCiszCert.ps1`.

После перезагрузки (или входа) хелпер запишет в `cert=` имя сертификата текущего
врача, и окно выбора сертификата при отправке в ЦИСЗ больше не появится.

## Ручное использование

```
powershell -NoProfile -ExecutionPolicy Bypass -File C:\MAP\Avest\SetCiszCert.ps1            # автоопределение
powershell -NoProfile -ExecutionPolicy Bypass -File C:\MAP\Avest\SetCiszCert.ps1 -Show      # показать имя
powershell -NoProfile -ExecutionPolicy Bypass -File C:\MAP\Avest\SetCiszCert.ps1 -Restart   # + перезапуск агента
powershell -NoProfile -ExecutionPolicy Bypass -File C:\MAP\Avest\SetCiszCert.ps1 -Name "Фамилия И.О."  # вручную
```

## Как это соотносится с выбором «один раз»

Врач один раз задаёт понятное имя сертификата в certmgr.msc (как уже делает).
Хелпер читает это имя и фиксирует его в `cert=`. После этого все пакеты (10 и более)
подписываются автоматически — появляется только окно пароля, которое уже
обрабатывает NTClientTool.
