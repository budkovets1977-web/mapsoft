ИНСТРУКЦИЯ ПО ПЕРЕХОДУ НА НОВУЮ ВЕРСИЮ ВЕБ-СЕРВЕРА MapWebServer x64

1.  Для установки веб-сервера на те же порты, что были ранее выполнить
    uninstall.bat в предыдущем каталоге сервера. Внимание, серверов может
    быть запущено несколько, для разделения ресурсов и обхода ограничений
    32-битной версии.
    
2.  Скопировать из релизов инсталяционный пакет 64-битной версии веб-сервера
    в новый каталог.
    
3.  Скопировать корневой каталоги cfg\* и crt\* предыдущей версии в новую -
    регистрация и настройки двух версий идентичны.
    
Остальные инструкции по новой установке, обновлению, управлению и регистрации
остались прежними.

Важные отличия от предыдущей версии для администрирования.

-   Инсталяция (install.bat) теперь будет устанавливать две новые службы.
    - Redis
    - Map Web Assist
    Необходимо следить в консоле при инсталяции или рестарте что они запускаются
    без ошибок.
-   Каталог с исполняемыми файлами PHP (bin\php\*) теперь объединен с APACHE
    (bin\apache\bin), соответственно файлы настройки php.ini и другие искать
    в новом каталоге. Это важно, если меняли настройки в 32-битной версии.
