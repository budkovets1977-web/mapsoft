ИНСТРУКЦИЯ ПО УСТАНОВКЕ И ОБНОВЛЕНИЮ ВЕБ-СЕРВЕРА MapWebServer

УСТАНОВКА (НОВАЯ)

1.  Копируем папку с инсталяционным пакетом веб-сервера (полученного из
    "Релизы\Web\номер_версии\MapWebServer"), со всем содержимым, в папку с другими
    нашими продуктами (чаще всего "D:\MAPSOFT\"). Папка MapWebServer не должен
    находиться внутри папок с русскими буквами или пробелами.

2.  Все дальнейшие операции по управлению веб-сервром выполняем через запуск bat-файлов
    находящихся в корне папки MapWebServer. Файлы запускать надо из каталога MapWebServer
    через командную строку cmd.exe, запущенного с правами Администратора.

3.  Выполняем install.bat. Первый раз данная команда не инсталлирует службу сервера, а
    выполняет подготовку файлов для его настройки.

4.  Редактируем появившийся файл cfg\ini.bat, в частности название службы, IP-адреса,
    разрешенные протоколы, порты и другое. Файл содержит подробное описание параметров.
    
5.  При необходимости, для более тонкой настройки доступа к веб-приложениям и сервисам,
    редактируем файл cfg\vhosts.ini. Он позволяет в рамках одного установленного
    экземпляра (каталога) веб-сервера, определить для любых задач или групп задач
    протоколы, порты и доменные/поддоменные имена в любых вариантах. а настройка
    позволит устанавливать и обновлять одну версию веб-сервера для выполнения любых
    веб-задач, а также, например ограничить выполняемые функции (например включить
    только медицинскую задачу Регистратура или только сервис для приема медосмотров).
    Подробное описание настройки и примеров находится в том же файле cfg\vhosts.ini.

6.  Редактируем файл cfg\config.json для настройки подключения к базе данных и 
    особых параметров конфигураций, например путь к исполняемым файлам МАП для печати
    отчетов, максимального времени ожидания сервера и других. Возможные параметры
    описаный в этом же файле.
    
7.  Существуют дополнительные параметры для всех веб-приложений и специальных по
    задачам, которые можно настройить в файлах cfg\settings_???.json. Параметры
    описаны в самих файлах конфигурации или в инструкциях по работе с задачами.
    
8.  При использовании SSL (включенном в п.4), необходимо создать файлы сертификатов,
    выполнив sslkey.bat. В MapWebServer появится каталог crt\ с сертификатами.
    Так как сертификаты "самоподписанные", на рабочих местах клиентов необходимо
    вгрузить в браузеры (или ОС если это мобильные устройства) доверенный
    сертификат crt\mapsoftCA.crt.
    
9.  После вcех настроек, повторно выполняем команду install.bat. Если настройки
    верны, Windows-служба Apache будет успешно запущена, а в файле
    MapWebServer\log\apache\error.log не будет сообщений об ошибках при запуске.
    
    
ОБНОВЛЕНИЕ ВЕРСИИ

1.  Все дальнейшие операции по управлению веб-сервром выполняем через запуск bat-файлов
    находящихся в корне папки MapWebServer. Файлы запускать надо из каталога MapWebServer
    через командную строку cmd.exe, запущенного с правами Администратора.

2.  Останавливаем и деинтсаллируем службу существующего веб-сервера командой uninstall.bat.
    
3.  Сохранить копию всего старого каталога MapWebServer в место хранения Backup-файлов.

4.  Копируем папку с инсталяционным пакетом веб-сервера (полученного из
    "Релизы\Web\номер_версии\MapWebServer"), со всем содержимым, в папку старого
    веб-сервере с заменой всех файлов. Внимание! Не удаляйте и не заменяйте файлы
    из старых папок MapWebServer\cfg, MapWebServer\crt, MapWebServer\log.
    
5.  Перенастраиваем, при необходимости, файлы конфигурации, аналогично пунктам 4-7
    из главы УСТАНОВКА.
    
6.  Инсталлируем и стартуем сервер командой install.bat.
    
РЕГИСТРАЦИЯ

1.  После старта веб-сервера, необходимо зайти в браузере на страницу приложениям
    и попробовать открыть форму авторизации (логин пользователя). Будет выдано
    сообщение что требуется регистрация программы. Только после этого в каталоге
    MapWebServer\crt появится файл запроса регистрационного ключа WebAuth.mrq.
    
2.  Данный файл используется для получения в отделе технической поддержке
    ответного файла-ключа с расширением mky.

3.  Файл-ключ надо поместить в папку MapWebServer\crt.

4.  Командой restart.bat (или последовательным выполнением stop.bat и start.bat)
    перезапустить веб-сервер.
    
5.  Обновить страницу с приложением в браузере и убедиться что регистрационный
    ключ разрешает доступ к нужным задачам.
