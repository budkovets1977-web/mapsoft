Настройки расширения:
ID приложения Mapsoft Tools App
Чтобы получить AppID необходимо на странице расширений включить режим разработчика, затем установить распакованное приложение Mapsoft Tools App, после чего скопировать значение поля "Идентификатор" в установленном приложении и вставить в поле "ID приложения Maposft Tools App"
