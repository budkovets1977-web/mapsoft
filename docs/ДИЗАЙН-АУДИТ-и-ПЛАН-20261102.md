## 1. Главное: иконки-«заглушки» в навигаторе (P0)

**Факт.** У половины задач навигатора вместо иконок — просто **первые буквы названий** из шрифта FontAwesome: класс `icons-letter-ru-N` рендерит литеру А–Я (У+0410–042Ф):

| Задача навигатора | Текущая «иконка» |
|---|---|
| Диспансерные осмотры взрослого населения | буква **В** |
| Диспансерные осмотры детского населения | буква **Д** |
| Журнал обследований | буква **О** |
| Журнал направлений | буква **Н** |
| Журнал выдачи справок | буква **Р** |

Это ровно та «неинформативная» картина, что замечена на глазок: серо-синие буквы В/Д/О/Н/Р в столбик ничего не говорят глазу, поиск задачи ведётся чтением, а не узнаванием.

**Предложение.** Заменить на смысловые глифы из уже встроенного шрифта `map-icons` (148 глифов, используется только 63):

| Задача | Предлагаемая иконка (`map-icons-…`) |
|---|---|
| Диспансерные осмотры (взрослые) | `med-patient-dispensary` |
| Диспансерные осмотры (детские) | `day-care` |
| Журнал обследований | `analyzer-results` (или `med-lab-studies`) |
| Журнал направлений | `paper-plane` |
| Журнал выдачи справок | `certificate` |
| Журнал медицинских документов (сейчас `fa-book`, дублируется со «Справочниками») | `med-functional-studies` или `filled-page` |
| Справочники | `book` (оставить, но убрать дубль) |

**Трудоёмкость:** минимальная — иконки приходят с сервера в данных задач (`iconCls`), значит правка делается **в теме CSS**: перекрыть селекторы `.icons-letter-ru-N` на нужные глифы, не трогая сервер и JS. Секция 23 темы.

## 2. Несогласованность иконок: три системы вперемешку (P1)

**Факты (статистика по коду):**
- `x-fa fa-…` — 149 употреблений, `fa fa-…` (без `x-fa`) — 80. Второй вариант в ExtJS 7 рендерится без обязательного класса `x-fa` — иконки получаются разного размера/смещения.
- `map-icons …` — 63 уникальных; `svg-icon` / фон-SVG — 73 класса; плюс единичные `icon-pencil`, `icon-dot` и пр.
- Одна и та же функция рисуется разными значками в разных окнах: печать — `icon-printer`, `fa-print`, `map-icons-action-printer`; удалить — `action-trash`, `fa-times`, `action-delete-icon`; редактировать — `action-edit`, `icon-pencil`, `fa-pencil`.

**Предложение (P1).** Ввести «словарь иконок» действий и привести к нему через CSS-секцию 23 (где возможно) и точечные JS-правки (где iconCls в конфиге):
- печать → `action-printer`; удалить → `action-trash`; редактировать → `action-edit`; добавить → `action-plus`; посмотреть → `action-eye`; закрыть → `action-close`; обновить → `action-refresh`; фильтр → `funnel-filter`; поиск → `action-search`.
- Все `fa fa-` → `x-fa fa-` (механическая замена, 80 шт., безопасна — это просто класс в одной строке).

## 3. Несимметричные кнопки (P1)

**Факты:**
- `iconAlign`: left = 12, **right = 45**, center = 7. У большинства кнопок «текст+иконка» иконка справа, у части — слева; в одном тулбаре вперемешку.
- Кнопки «Сегодня»/«Завтра» в календаре записи — **48px высотой** (внутр. line-height 32px) при стандартной высоте кнопки темы 34px — глядятся пухлыми, текст «плавает».
- Кнопка «Доп.» (запись на приём) — обрезанное «Дополнительные талоны»; рядом кнопки с полными подписями.
- Сегментные фильтры талонов — однобуквенные «**Все / C / З / В / О**» (свободные/заказанные/выданные/отменённые) — без пояснений на кнопках, только tooltip.

**Предложения (P1):**
1. CSS: выровнять высоту всех кнопок тулбаров на 34px (`line-height` пересчитать) — уже частично сделано темой; довести для тулбара календаря (секция 22/23).
2. JS: единый `iconAlign:'right'` для кнопок «текст+иконка» (45 уже так; поменять 12 исключений списком).
3. «Доп.» → «Ещё талоны» или иконка+tooltip (по месту).
4. Сегментные фильтры: добавить иконки-подсказки (`action-checkmark` — все, `action-clock` — заказанные, `action-checkmark-circle` — выданные, `action-close` — отменённые) и оставить текст; tooltip сохранить.
5. Кнопка «Что нового» (101×34, висит внизу слева рядом с «Версия») — перенести в шапку как иконку с tooltip или в меню пользователя; в taskbar оставить только версию.

## 4. Логотип и шапка (P2)

**Факты:**
- Логотип в шапке входа/выбора приложения — это **глиф шрифта** `map-icons-logo-mapsoft` (e962), 24×24, синий. Настоящий векторный логотип `logo-mapsoft.svg` (173×48, белая версия, opacity .7) лежит в resources, но в шапках не используется.
- Шапка приложения: текст «Поликлиника … Будковец» в заголовке панели + 3 иконки FontAwesome (user, вопрос, выход) справа; «Версия: 6.00.54» и «Что нового» — внизу слева в taskbar. Лого в шапке приложения нет вообще.

**Предложения (P2):**
1. В шапку приложения (левый край) добавить лого-блок: глиф e962 20px в кружке/без + текст «МАПСОФТ» тонким 12px в 2 строки не нужно — достаточно глифа и имени задачи рядом; это создаёт «фирменный якорь» на всех экранах.
2. На экране выбора приложения заменить строку «глиф + МАПСОФТ» на настоящий SVG `logo-mapsoft.svg` (перекрасить в синий ink-900: SVG с fill #FFF → перекраска через CSS filter или добавить цветную копию файла).

## 5. Строки и списки (P2)

**Факты:**
- Строки пациентов листа врача (card-container) — табличная вёрстка вендора с inline-стилями; высота строк «пляшет» из-за переносов адреса/телефонов.
- Строки документов карты (`document-container`) — уже выровнены секцией 14i (одна строка, ellipsis) — оставить как эталон.
- Адрес/телефоны в карточке пациента переносятся на 2–3 строки и ломают ритм сетки.

**Предложения (P2):**
1. Секция 23: для `card-container` задать фиксированную высоту строки (56–60px) с `overflow:hidden` на адресе + ellipsis, полный адрес в tooltip (механизм title уже есть у примечаний).
2. Телефоны — компактной строкой иконка+номер, тоже ellipsis.
3. Чётные/нечётные строки: чередование фона `--ms-surface-2` уже приятное — сохранить.
