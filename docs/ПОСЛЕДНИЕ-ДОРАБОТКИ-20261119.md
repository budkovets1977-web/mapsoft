# Последние доработки MapWebServer 6.00.60

Дата: 19.11.2026.

## ЦИСЗ / FHIR

- `Encounter.actualPeriod.end` не формируется без `HH2/MM2`; явный обратный период отклоняется.
- Пустой `ReasonForFunctDiagn` не создаётся без `FITX2`; ссылка на Condition сохраняется.
- Перед отправкой посещения проверяется ожидающая регистрация Patient; ошибка `-7301` помечается `retryable`.
- Потоковая отправка получает врача из `cbDoctor`, что исправляет работу у регистраторов и администраторов без `mapMedDoctor` в сессии.

Файлы:
- `src/service/app/med/cisz/traits/encounterTrait.php`;
- `src/service/app/med/cisz/traits/serviceRequestTrait.php`;
- `src/service/app/med/cisz/sendByDate.php`;
- `src/desktop/build/production/*/app.js` и `resources/common.css`.

## Интерфейс

### Потоковая отправка
- «Отправка» — зелёная; «Закрыть» — красная.
- Кнопки переставлены без изменения обработчиков.
- Даты и ошибки выводятся в понятном виде.

### Отчёты
- «Сформировать» — зелёная сплит-кнопка с тёмно-зелёной областью стрелки.
- «Закрыть» — красная, 100×34 px.

### Панель амбулаторных карт
- Поле выбора врача: 450 px, `flex=0`.
- Настройки: 60 px, `fa-sliders`.
- Сортировка: 140 px, `fa-sort-amount-desc`.
- Печать: 112 px, `fa-print`; единый тёплый фон и тонкий разделитель перед стрелкой.
- Отправка в ЦИСЗ: 56 px, `fa-paper-plane`.
- Добавление пациента: 56 px, `fa-user-plus`.
- Для трёх тем применяется повторяемый patch в `app.js`; постоянные стили находятся в `resources/common.css`.
- Inline-цвета вендора заменяются после рендера кнопок через `setProperty(..., 'important')`.

## Автоматизация ЭЦП

Эталонный пакет включает:
- `automation/cisz-cert-autoselect/` — выбор friendly name сертификата и запись в `cert=` секции `[sigma]` в Windows-1251;
- `automation/cert-ok-watcher/` — автоматическое нажатие «ОК» через UI Automation после первого ручного подтверждения.

Установка выполняется на каждой рабочей станции от пользователя МИС; подробности — в README соответствующих папок.
