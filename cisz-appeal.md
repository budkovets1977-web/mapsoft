Обращение в ЦИСЗ / Mapsoft
==========================

**Тема:** Пополнение справочника МКБ-10 в ЦИСЗ (ValueSet, CiszResourceCode=195): отсутствуют коды серий «*B» и классические коды со звёздочкой/плюсом.

Уважаемые коллеги!

При регистрации медицинской документации (амбулаторные посещения, случаи ВН) сервер ЦИСЗ отклоняет документы с диагнозами, коды которых отсутствуют в ValueSet МКБ-10, ошибкой «No code supplied».

Сравнение нашего классификатора (МКБ-10, редакция с уточняющими суффиксами) со справочником ЦИСЗ показало: отсутствуют 1872 кода, из них 202 используются в реальной документации. В приоритете — серия «без АГ»: I25B, I20B, I67B, I67.2B, I25.9B и классические коды со звёздочкой: H36.0*, G63.2*, I43*. Серия «на фоне АГ» (*A) в справочнике присутствует.

Просим пополнить ValueSet указанными кодами либо сообщить регламент их замены. Статистика использования прилагается.

## Ключевые данные

- Всего отсутствует в справочнике ЦИСЗ: **1872** кода.
- Из них реально используются в МИС: **202** кода.
- Наиболее часто используемые недостающие коды:

| Код | Использований в документации | Наименование |
|---|---|---|
| I25B | 22552 | Хроническая ишемическая болезнь сердца без АГ |
| H36.0* | 3097 | Диабетическая ретинопатия |
| I67B | 2885 | Другие цереброваскулярные болезни без АГ |
| M51.5 | 1230 | Дискогенный радикулит |
| I67.2B | 1017 | Церебральный атеросклероз без АГ |
| I25.9B | 895 | Хроническая ишемическая болезнь сердца неуточненная без АГ |
| G63.2* | 880 | Диабетическая полиневропатия |
| I20B | 797 | Стенокардия [грудная жаба] без АГ |
| I43* | 739 | Кардиомиопатия при болезнях, классифицированных в других рубриках |
| I67.9B | 658 | Цереброваскулярная болезнь неуточненная без АГ |

Полная статистика использования отсутствующих кодов приведена в прилагаемом файле `cisz-missing-icd10-usage.txt`.

Просим рассмотреть обращение и сообщить решение.
